## 实验

> OnEnable / OnDisable 事件注册

**目的**：
验证为什么 OnDisable 中必须取消事件订阅。

**步骤与源码**：

```cs
<ActiveControllor>
public Button printLogButton;  
public Button ActiveButton;  
private bool isActive = true;  
private void OnEnable()  
{  
    ActiveButton.onClick.AddListener(() =>  
    {  
        if (isActive)  
        {   
	        isActive = false;  
            printLogButton.gameObject.SetActive(false);  
        }        
        else  
        {  
            isActive = true;  
            printLogButton.gameObject.SetActive(true);  
        }    
    });
}

<printLog>
public Button printLogButton;  
private void OnEnable()  
{  
    printLogButton.onClick.AddListener(() => Debug.Log("Button clicked!"));  
}
```

通过不断点击ActiveButton，控制printButton激活状态更改。

**结果**：
点击printButton后，一个事件触发三次。

**解决与理解**：

添加 OnDisable 方法Clear所有事件监听即可。

事件不会因为对象隐藏而自动解除，
OnEnable 每执行一次都会再次订阅。
`+=` 必须对应 `-=`，
否则会造成重复监听、内存泄漏、空引用等问题。
